Website portofolio interaktif dan modern yang dirancang khusus untuk **Isa Muhammad** (Mahasiswa D4 Teknologi Rekayasa Perangkat Lunak, Universitas Gadjah Mada). Portofolio ini menampilkan latar belakang akademis, pengalaman profesional/organisasi, showcase proyek-proyek unggulan, keahlian teknis, live preview CV, dan formulir kontak interaktif.

---

## ✨ Fitur Utama

- 💎 **Pure Glassmorphism Floating Navbar**: Navigation bar melayang (*floating pill*) di bagian atas layar dengan transparansi kristal, backdrop blur, serta dukungan pergantian mode **Light & Dark** yang ultra-smooth.
- ⚡ **Animated Cyber Hero Grid**: Latar belakang grid 60px beranimasi pergerakan dinamis (*10s panning animation*) di Hero Section dipadukan dengan *typewriter effect* untuk peran profesional.
- 🌈 **Rainbow Particle Trail Cursor**: Efek kursor dinamis di Hero Section yang menghasilkan ekor titik-titik partikel pelangi (*hue shift*) yang perlahan menghilang saat kursor digeser.
- 🖼️ **Profile Photo Integration**: Menampilkan foto resmi berseragam almamater UGM dengan highlight kualifikasi akademis.
- 🌊 **Seamless Section Background Flow**: Desain latar belakang unik pada tiap section (*Diagonal Stripes, Dot Matrix, Crosshairs, Constellation Nodes, Hex Mesh*) yang menyambung secara lembut tanpa potongan garis kaku.
- 📁 **Interactive Project Showcase**: Filter kategori proyek (*All, Fullstack, Backend, AI & Automation, Management*) lengkap dengan modal spec detail.
- 📑 **Live Curriculum Vitae Preview**: Embed Google Docs iFrame resmi sehingga pengunjung dapat membaca CV tanpa perlu mengunduh terlebih dahulu.
- 📱 **Fully Responsive Layout**: Tampilan optimal untuk perangkat Mobile, Tablet, dan Desktop.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## 🚀 Cara Menjalankan Project Secara Lokal

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/isamuha36/web-portofolio.git
   cd web-portofolio
   ```

2. **Install Dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```

4. Buka **[http://localhost:3000](http://localhost:3000)** di browser Anda.

---

## 📦 Build & Production

Untuk membangun bundle siap rilis:
```bash
npm run build
npm run start
```
